# NovaVPN

Современный Android-клиент для VPN-конфигов и подписок.

Улучшенная версия HAPP с акцентом на удобство:

- **Материал 3 + тёмная тема** — мягкий фиолетово-бирюзовый дизайн
- **Протоколы**: VLESS (Reality), VMess, Trojan, Shadowsocks, Hysteria2, TUIC
- **Подписки** с автообновлением при запуске и по расписанию
- **Обход приложений** — глобальный режим или выборочный список + инверсия
- **Избранные серверы**, поиск, задержки, быстрые действия
- **Живая статистика** трафика и скорости
- Импорт по URL / ссылкам vless:// vmess:// и др.

## Сборка

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Примечание

Приложение — полноценный UI-клиент менеджера конфигов. Реальное VPN-ядро (Xray) можно подключить отдельно через libxray / sing-box в production-сборке.
